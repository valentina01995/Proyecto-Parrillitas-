# Parrillitas CR

Proyecto académico del curso Desarrollo de Páginas Web del INA.

Sitio web sobre parrillas pequeñas y portátiles elaboradas con
cilindros reutilizados de aire acondicionado.

## Tecnologías
- HTML5
- CSS3

## Secciones
- Inicio
- Nosotros
- Servicios
- Contacto

## Cómo visualizarlo
Descargar los archivos del proyecto y abrir index.html en un navegador.

## Evidencia de avance
Este repositorio registra los archivos y cambios realizados durante el curso.
